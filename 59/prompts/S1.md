> A binary tree is either the empty list `()`, or a three-element list `(value left right)` where `left` and `right` are binary trees.
>
> Implement:
> 1. Tree accessor helpers: `tree-val`, `tree-left`, `tree-right` using allowed built-ins `car`, `cadr`, `caddr`.
> 2. An accumulator-based helper `(inorder-helper tree acc)` that returns the inorder value list without using `append`.
> 3. `(inorder tree)` which invokes `(inorder-helper tree '())`.
> 4. `(print-inorder tree)` which prints on one line using `display` the list of values in inorder (left subtree, node, right subtree), followed by `(newline)`.

> - STRICTLY FORBIDDEN: `set!`, `length`, `append`, `reverse`, `map`, `filter`, `member`, loops (`do`, `for`).
> - Empty tree `()` must print `()`.
> - For `t1 = (4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ())))`, `(print-inorder t1)` must print `(1 2 3 4 5 6 7)`.

## Prompt 3 — Tree height, leaf count, and print-height-and-leaves (S1.c)

> Continue S1 of CS F301 Assignment 2, Group 59.
>
> Read and follow `59/skills/scheme-dev/SKILL.md`.
>
> Modify only `59/code/59_q3.rkt`.
>
> Implement:
> 1. `(tree-height tree)`: returns the height of the tree as an integer.
>    - Height of `()` is 0.
>    - Height of a node is `1 + max(left-height, right-height)`. Single node has height 1.
> 2. `(leaf? tree)`: helper predicate checking if both left and right subtrees are `()`.
> 3. `(tree-leaf-count tree)`: returns the number of leaves as an integer.
>    - Empty tree `()` has 0 leaves.
>    - Leaf node has 1 leaf.
>    - Internal node has `left-leaves + right-leaves`.
> 4. `(print-height-and-leaves tree)`: prints on one line using `display` the list `(height leaf-count)`, followed by a newline.
>
> Rules:
> - Use only allowed built-ins: `+`, `max`, `null?`, `and`, `if`, `cond`, `list`, `display`, `newline`.
> - For `t1`: prints `(3 4)`.
> - For `t2`: prints `(3 1)`.
> - For `t3 = (a (b () ()) (c () ()))`: prints `(2 2)`.
> - For empty tree `()`: prints `(0 0)`.
> - For single node `(42 () ())`: prints `(1 1)`.
> - No top-level calls or printing on load.
