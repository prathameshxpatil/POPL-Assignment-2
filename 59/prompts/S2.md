## Prompt 2 — Higher-order make-inserter and insert-if-short (S2.c)

> Continue S2 of CS F301 Assignment 2, Group 59.
>
> Read and follow `59/skills/scheme-dev/SKILL.md`.
>
> Modify only `59/code/59_q4.rkt`.
>
> Implement:
> 1. Higher-order function `(make-inserter x len-ok?)`:
>    - Takes atom `x` and predicate `len-ok?`.
>    - Returns a procedure of one argument (a list) that inserts atom `x` at the front of every list whose original length satisfies `(len-ok? len)` at every level of nesting.
>    - Original length is measured on top-level elements before insertion.
>    - Empty list `'()` has length 0, becoming `(x)` if `(len-ok? 0)` is true.
>    - Non-list atoms inside the list remain unchanged.
>    - Must work for nested lists up to depth 100 and lists up to 10,000 elements without stack overflow.
> 2. `(insert-if-short x lst n)`:
>    - Inserts atom `x` at the front of every list whose original length is less than `n`, at every level of nesting.
>    - Must be defined strictly using `make-inserter`:
>      ```racket
>      (define (insert-if-short x lst n)
>        ((make-inserter x (lambda (len) (< len n))) lst))
>      ```
>    - Note: The file must contain ONLY this single definition of `insert-if-short`.
>
> Rules:
> - Use only allowed primitives (`define`, `lambda`, `letrec`, `let*`, `if`, `cons`, `null?`, `pair?`, `not`, `or`, `<`, etc.).
> - No forbidden functions.
> - Do not call functions at top level.
