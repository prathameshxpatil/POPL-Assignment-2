# Prompts for P1: Department Assignment Puzzle

## Prompt 1 — Solution template and domain facts
> Write a Prolog predicate `solution_template/1` for a constraint satisfaction puzzle. A solution is a list of four terms `p(Name, Dept, Lang, Project)` for Alex, Ben, Carla, Dana (in that order, as quoted atoms). Each attribute domain has four values used exactly once: departments are research, development, design, testing; languages are python, java, 'c++', javascript; projects are 'AI', web, embedded, data. Use `permutation/2` from library(lists) to generate all valid assignments. Also define domain facts `dept/1`, `lang/1`, `project/1`.

## Prompt 2 — Clue predicates 1–4
> Write Prolog clauses `clue(N, Solution)` for clues 1 through 4. Each clue gets its own clause. Clue 1: The friend who prefers the AI project does not work in research and is not Dana. Clue 2: Alex does not work in development and does not prefer C++. Clue 3: The friend working in the testing department likes Python. Clue 4: Ben prefers web projects and does not work in testing. Use `member/2` to find the relevant person in the Solution list and `\=` for negative constraints.

## Prompt 3 — Clue predicates 5–8
> Write Prolog clauses `clue(N, Solution)` for clues 5 through 8. Clue 5: The friend whose favorite language is Java works in the design department. Clue 6: Carla's project preference is not embedded, and her department is not development. Clue 7: Dana's favorite language is not Java, and she works in research or testing. Clue 8: The friend who prefers data projects works in research and does not use JavaScript. Use `member/2` and `\=`. For clue 7, use a disjunction `(Dept = research ; Dept = testing)`.

## Prompt 4 — solve/1 and main/0
> Write `solve/1` that calls `solution_template/1` and then all eight `clue/2` predicates on the solution. Write `main/0` that finds one solution using `solve/1` with a cut, and prints four lines in this exact format: `Name = [Dept, Lang, Proj]` using `format/2`. Define a helper `print_person/1` for one line.

## Prompt 5 — count_solutions/2
> Write `apply_clues/2` that takes a list of clue numbers and a solution, and succeeds only when all those clues hold. Write `count_solutions(Active, N)` that uses `findall/3` to collect all solutions satisfying the clues in Active, then uses `length/2` to count them.

## Prompt 6 — Clue 9 (repair)
> There are 3 solutions with clues 1–8. Examine them and add a `clue(9, Solution)` that is true in exactly one of them and false in the other two, so that `count_solutions([1,2,3,4,5,6,7,8,9], 1)` holds. The clue must not mention any friend by name — only attribute values. Add a comment above it starting with `% CLUE 9:` with the English sentence.

## Prompt 7 — Review
> Review the entire P1 solution file for correctness. Check: no initialization directives, no halt/0, no assert/retract, all atoms properly quoted ('Alex', 'c++', 'AI'), output format matches spec exactly, each clue is a separate clause, and the file loads without warnings.
